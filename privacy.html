개인정보 처리방침

멍케어 Lab · 시행일 2026년 11월 18일

멍케어 Lab은 회원가입·로그인·서버 데이터베이스 없이 동작하는 정적 웹사이트입니다. 입력한 값은 이용자의 기기(브라우저)에만 저장되고 운영자에게 전송되지 않습니다. 이 방침은 실제 동작 방식에 맞추어 어떤 정보가 어디에 남는지 설명합니다.

1서비스의 구조

멍케어 Lab은 GitHub Pages로 제공되는 정적 웹페이지입니다. 회원가입·로그인 기능이 없고, 이용자의 입력을 받아 저장하는 서버나 데이터베이스를 운영하지 않습니다.

따라서 운영자는 이용자의 이름·전화번호·이메일·주소 등 개인을 식별할 수 있는 정보를 직접 수집하거나 보관하지 않습니다.

2이용자의 기기에 저장되는 정보

서비스는 화면을 다시 열었을 때 이전 입력을 그대로 보여주기 위해 브라우저의 localStorage(기기 저장소)를 사용합니다. 이 값은 이용자의 기기 안에만 남고, 서버로 전송되거나 운영자에게 전달되지 않습니다.

저장 키저장되는 값목적
mc_state_v1 체중, 나이 단계, 중성화 여부, 관심 부위, 사료 열량, 급여 중인 제품 선택, 견종, 알러지 선택, 직접 추가한 제품 급여량 계산·진단·리포트 화면의 입력값 유지
mc_requests_v1 제품 등록 요청에 입력한 제품명·브랜드명·상세 페이지 URL·작성 시각(최대 30건) 요청서를 다시 열어 복사할 수 있도록 기기에 임시 보관

제품 등록 요청은 관리자에게 자동 전송되지 않습니다. 화면에서 요청서를 복사해 이용자가 직접 전달하는 방식이며, 실제 접수·수집을 위해서는 별도의 폼 서비스나 서버 연결이 필요합니다.

이 값들은 서비스 화면의 “데모 상태 초기화” 버튼으로 지우거나, 브라우저 설정에서 해당 사이트의 데이터를 삭제하여 언제든지 직접 지울 수 있습니다.

3쿠키·추적 도구

서비스는 쿠키를 사용하지 않습니다. 방문 통계(애널리틱스), 광고, 리타게팅, 제3자 추적 스크립트도 넣지 않았습니다.

화면에 표시되는 제품 이미지와 데이터 파일은 모두 같은 사이트 안에서 불러오며, 외부 서버로 이용자의 접속 정보를 보내는 스크립트는 없습니다.

4호스팅 사업자를 통한 접속 기록

서비스는 GitHub Pages(GitHub, Inc.)로 호스팅됩니다. 웹사이트를 제공하는 과정에서 호스팅 사업자는 접속 IP 주소, 브라우저·기기 정보, 요청한 페이지와 시각 등 통상적인 서버 접속 기록을 처리할 수 있습니다.

이 기록은 호스팅 사업자의 정책에 따라 처리되며, 운영자는 개별 이용자의 접속 기록을 제공받지 않습니다(저장소 관리 화면에서 확인할 수 있는 것은 집계된 방문 수준의 통계입니다). 호스팅 사업자의 처리 방식은 GitHub의 개인정보 처리방침을 따릅니다.

5외부 쇼핑몰로 이동하는 경우

서비스의 네이버 쇼핑 검색·쿠팡 검색 버튼과 제품별 구매 링크는 새 탭에서 해당 쇼핑몰을 엽니다. 이동한 뒤에는 그 사이트의 개인정보 처리방침과 쿠키 정책이 적용됩니다.

서비스는 외부 쇼핑몰에서 이루어지는 회원가입, 검색, 구매, 결제, 배송 정보의 처리에 관여하지 않으며, 해당 정보를 제공받지 않습니다. 서비스는 제휴(어필리에이트) 링크를 사용하지 않습니다.

6개인정보의 제3자 제공 및 처리 위탁

운영자는 이용자의 개인정보를 수집하지 않으므로 제3자에게 제공하거나 처리 업무를 위탁하지 않습니다. 서비스 운영을 위해 별도의 외부 폼·설문·메일 발송 서비스를 연결하고 있지 않습니다.

7이용자의 권리와 행사 방법

  • 기기에 저장된 값은 이용자가 직접 확인·수정·삭제할 수 있습니다. 앱 화면의 “데모 상태 초기화” 버튼은 저장된 계산·진단 입력값을 삭제합니다.
  • 브라우저 설정에서 사이트 데이터(저장소)를 삭제하면 등록 요청 목록을 포함한 모든 기기 저장 값이 지워집니다.
  • 운영자는 개인정보를 보관하지 않으므로, 운영자에 대한 열람·정정·삭제 요구의 대상이 되는 개인정보가 없습니다.

8보유 기간

운영자가 별도로 보유하는 개인정보가 없습니다. 기기에 저장된 값은 이용자가 삭제할 때까지 이용자의 브라우저에 남습니다.

9아동의 개인정보

서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 수집하지 않습니다.

10방침의 변경

서비스의 기능이나 데이터 처리 방식이 바뀌면 이 방침을 그에 맞게 수정합니다. 변경할 때에는 변경 내용과 시행일을 이 페이지에 게시합니다.

11시행일

이 개인정보 처리방침은 2026년 11월 18일부터 적용됩니다.

이 사이트는 로그인 없이 사용하며, 입력한 값은 기기에만 저장됩니다. 공용 기기에서 사용했다면 브라우저 데이터를 삭제해 주세요.
